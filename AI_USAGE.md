# AI Usage Documentation

## 1. AI Tools Used

The following AI tool was used during the development of this project:

- **ChatGPT (OpenAI):** Used as an assistant for understanding requirements, discussing implementation approaches, troubleshooting errors, and improving project documentation.

## 2. How AI Was Used

AI assistance was used in the following areas:

### Requirement Analysis
- Helped understand the school admission system requirements.
- Discussed the student admission workflow, seat availability, application holds, and confirmation process.
- Helped identify possible edge cases and clarify implementation assumptions.

### Architecture and Technical Guidance
- Discussed the project structure and responsibilities of the frontend, backend, and database.
- Explored approaches for handling concurrent admission requests.
- Discussed Docker Compose configuration and container communication.

### Development Assistance
- Used AI suggestions when investigating implementation issues.
- Discussed API request and response handling.
- Reviewed possible approaches for validation, error handling, and database operations.

### Documentation
- Used AI assistance to organize and improve the README documentation.
- Helped document project assumptions, setup instructions, and API endpoints.

## 3. Human Review and Responsibility

AI was used as a development assistant, not as a replacement for understanding or reviewing the implementation.

- AI-generated suggestions were reviewed before being used.
- Project-specific decisions and implementation choices were checked against the assignment requirements.
- Final responsibility for the submitted source code, configuration, and documentation belongs to the developer.

## 4. Important Note

AI assistance was used to support development, problem-solving, and documentation. The final implementation should be evaluated based on the actual submitted source code and its behavior.
